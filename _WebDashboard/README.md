# How to Run Retentia Web Dashboard

1. Open a terminal in this folder (`Retentia AI\_WebDashboard`).
2. Run `npm install` (if you haven't already).
3. Run `npm run dev`.
4. Open the link shown (usually `http://localhost:5173`).

The dashboard will automatically sync with the running Unity project.
Start the Unity scene (with Bootstrapper) to see real-time data.
